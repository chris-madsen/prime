How it works

The UI calls a local Rust HTTP server, which then invokes the project runtime directly. Queries prefer the committed wheel210 archive when the requested number lies inside the queryable range, and can fall back to direct E8-mask evaluation when the query is not archive-backed.

  • wheel210 archive — exact lookup from committed compressed chunks.
  • E8 mask filter — wheel-210 + small-prime sieve, eliminates candidates before Miller-Rabin.
  • Miller-Rabin (GMP) — probabilistic primality, 32–64 rounds with GMP-accelerated pow_mod.
  • ECPP (PARI/GP) — deterministic certificate via "Refine answer".
  • Local-only binding — v1 listens on 127.0.0.1 only.
