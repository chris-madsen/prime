# Опиши эту идею в маркдауне

Вот аккуратная версия в Markdown, которая описывает именно твою идею: **16 базовых состояний на тессеракте и 4 канала как 64-слотовую раскладку**.[^1][^2]

```markdown
# Тессеракт как контейнер для 4-канальной битовой симметрии

## Идея

Тессеракт удобно использовать как 4D-контейнер для компактного кодирования симметрии битовых масок.

У него есть:
- 16 вершин;
- 32 ребра;
- 24 квадратные грани;
- 8 кубических ячеек [web:132].

В нашей схеме 16 вершин тессеракта играют роль **16 базовых позиций** одного опорного канала `...1`.

## Базовый канал

Сначала строится одна базовая маска для канала `...1`.

Она задаёт:
- какие позиции в периоде выбиваются;
- где находится первичная орбита;
- как выглядит один минимальный шаблон маски [file:3].

Эту базовую маску можно разместить на 16 вершинах тессеракта как набор из 16 базовых состояний.

## Получение остальных каналов

Остальные три канала `...3`, `...7`, `...9` получаются из базового канала действием циклической симметрии.

Эта симметрия соответствует группе порядка 4:
- `...1 -> ...3`
- `...3 -> ...9`
- `...9 -> ...7`
- `...7 -> ...1` [file:3].

Таким образом, одна базовая маска генерирует ещё три канала.

## Полная раскладка

Если у нас:
- 16 базовых позиций на тессеракте;
- 4 канала `...1`, `...3`, `...7`, `...9`;

то полное пространство состояний имеет размер:

$ 16 \times 4 = 64 $

Это означает, что тессеракт может служить компактным 64-слотовым контейнером для всех каналов маски.

## Что именно кодируется

Важно различать два уровня:

1. **Геометрический уровень** — тессеракт как 16 вершин и 32 ребра.
2. **Информационный уровень** — 64 состояния `вершина × канал`.

На геометрическом уровне мы не говорим о 64 рёбрах.
На информационном уровне мы говорим о 64 кодируемых слотах.

## Почему это удобно

Такая схема даёт три преимущества:

- одна базовая маска хранит минимальный шаблон;
- остальные каналы восстанавливаются симметрией;
- вся структура естественно ложится на 4D-симметрию тессеракта.

## Итог

Тессеракт здесь — это не просто визуальная метафора, а компактная 4D-решётка для хранения и разворачивания битовых масок.

Базовых позиций — 16.
Каналов — 4.
Всего состояний — 64.
```
