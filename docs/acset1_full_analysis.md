# Математический и геометрический анализ оптимизированного решета Эратосфена (Acset1.xlsx)

## 1. Введение: концепция оптимизированного решета

### 1.1. Базовый принцип отсева по модулю 10

Классическое решето Эратосфена проверяет все натуральные числа подряд. Однако любое простое число, большее 5, оканчивается только на одну из четырёх цифр: **1, 3, 7, 9** — так как все остальные окончания дают делимость на 2 или 5. Это означает, что из каждых 10 последовательных натуральных чисел можно сразу исключить 6 кандидатов, не тратя на них никаких вычислений.

Оптимизированное решето пользуется этим принципом, рассматривая только четыре арифметические прогрессии:

\[ 10k+1, \quad 10k+3, \quad 10k+7, \quad 10k+9, \quad k = 0, 1, 2, \ldots \]

Это сразу уменьшает рабочее пространство в 2.5 раза по сравнению с классическим вариантом.

### 1.2. Обзор структуры файла `Acset1.xlsx` (Лист E)

Файл `Acset1.xlsx` содержит пять листов: **A, B, C, D, E**. Лист `E` является основным вычислительным листом и содержит 147 строк и 24 колонки (A–X). Структура листа делится на два слоя:

- **Строки 1–5** — служебный заголовочный блок: легенда hex-символов, опорные значения `840, 1680, 2520, 3360, 4200`, текстовые подписи.
- **Строки 6–147** — рабочая таблица, где каждая строка соответствует одному простому числу `p`.

Ключевая цепочка колонок в рабочей таблице:

| Колонка | Содержимое |
|---------|------------|
| `F` | Простое число `p` |
| `G` | Полная маска \(G_p\) — включая самовычёркивание `p` |
| `E` | Очищенная маска \(E_p\) — `p` восстановлено как допустимое |
| `H` | Четыре специальных hex-символа из `G` в порядке их появления |
| `I` | Первый символ из `H` |
| `J` | Позиция первого специального символа в `G` |
| `K–X` | Вспомогательная арифметика: остатки и дополнения для 840, 1680, 2520, 3360, 4200 по модулю `p` |

## 2. Механика битовых масок

### 2.1. Кандидаты вида `10k + d`

Для каждого \(k \geq 0\) рассматриваются четыре кандидата:

\[ C_k = (10k+1,\ 10k+3,\ 10k+7,\ 10k+9) \]

Примеры:

- \(k=0\): 1, 3, 7, 9
- \(k=1\): 11, 13, 17, 19
- \(k=2\): 21, 23, 27, 29

Для каждого фиксированного простого числа `p > 5` ровно одно из четырёх уравнений

\[ 10k + d \equiv 0 \pmod{p}, \quad d \in \{1, 3, 7, 9\} \]

имеет решение на каждой позиции `k`. На большинстве позиций `k` ни один из четырёх кандидатов не делится на `p`.

### 2.2. Полная маска (G) и Очищенная маска (E)

**Полная маска** \(G_p\) — строка длины `p`, где символ на позиции `k` описывает, какой из четырёх кандидатов делится на `p`:

```
full_mask(p):
  for k in 0..p-1:
    если p делит 10k+1 → символ '7'
    если p делит 10k+3 → символ 'b'
    если p делит 10k+7 → символ 'd'
    если p делит 10k+9 → символ 'e'
    иначе             → символ 'f'
```

Проблема полной маски: само число `p = 10q + r` тоже попадает в маску как составное. Например, `13 = 10×1 + 3`, поэтому на позиции `k=1` стоит символ `b` — как будто 13 не является простым.

**Очищенная маска** \(E_p\) исправляет это: позиция \(q = \lfloor p/10 \rfloor\) заменяется на `f`:

\[ E_p[k] = \begin{cases} f & \text{если } k = \lfloor p/10 \rfloor \\ G_p[k] & \text{иначе} \end{cases} \]

Примеры сравнения полной и очищенной масок:

| `p` | Полная маска `G` | Очищенная маска `E` | Что заменено |
|-----|-----------------|---------------------|--------------|
| 11  | `f7fbfffdfef`   | `fffbfffdfef`       | позиция 1: `7` → `f` |
| 13  | `fbfefffff7fdf` | `fffefffff7fdf`     | позиция 1: `b` → `f` |
| 17  | `fdfff7fffffefffbf` | `fffff7fffffefffbf` | позиция 1: `d` → `f` |
| 19  | `fefffdfffffffbfff7f` | `fffffdfffffffbfff7f` | позиция 1: `e` → `f` |

### 2.3. Шестнадцатеричное (hex) кодирование состояний каналов

Для каждого `k` нужно хранить 4 бита — по одному на каждый канал. Четыре бита естественно кодируются одной hex-цифрой. Порядок битов: `(…1, …3, …7, …9)`.

| Hex-символ | Биты | Смысл |
|------------|------|-------|
| `f` | `1111` | все четыре канала живы, `p` здесь никого не выбивает |
| `7` | `0111` | выбит канал `…1` |
| `b` | `1011` | выбит канал `…3` |
| `d` | `1101` | выбит канал `…7` |
| `e` | `1110` | выбит канал `…9` |

Символ `f` (все единицы) означает «чисто»; символы `7, b, d, e` имеют ровно один нулевой бит, указывающий на выбитый канал.

## 3. Алгебраический фундамент: Теория групп

### 3.1. Мультипликативная группа кольца вычетов \((\mathbb{Z}/10\mathbb{Z})^\times\)

Числа 1, 3, 7, 9 — это не произвольный выбор. Это в точности все элементы множества \(\{1, 2, \ldots, 9\}\), взаимно простые с 10. Такие элементы образуют **мультипликативную группу** кольца вычетов по модулю 10:

\[ (\mathbb{Z}/10\mathbb{Z})^\times = \{1, 3, 7, 9\} \]

Операция в этой группе — умножение по модулю 10. Таблица Кэли:

| × mod 10 | 1 | 3 | 7 | 9 |
|----------|---|---|---|---|
| **1** | 1 | 3 | 7 | 9 |
| **3** | 3 | 9 | 1 | 7 |
| **7** | 7 | 1 | 9 | 3 |
| **9** | 9 | 7 | 3 | 1 |

Группа замкнута: произведение любых двух элементов снова лежит в \(\{1,3,7,9\}\). Порядок группы равен \(\varphi(10) = 4\), где \(\varphi\) — функция Эйлера.

### 3.2. Изоморфизм с группой Галуа кругового расширения \(\mathbb{Q}(\zeta_{10})/\mathbb{Q}\)

Круговое расширение \(\mathbb{Q}(\zeta_{10})\) — это поле, получаемое добавлением к рациональным числам примитивного корня 10-й степени из единицы:

\[ \zeta_{10} = e^{2\pi i/10} \]

Группа Галуа \(\text{Gal}(\mathbb{Q}(\zeta_{10})/\mathbb{Q})\) состоит из всех автоморфизмов этого поля, которые не трогают рациональные числа. Каждый такой автоморфизм \(\sigma_k\) действует по правилу:

\[ \sigma_k : \zeta_{10} \mapsto \zeta_{10}^k \]

Автоморфизм должен переводить примитивный корень в примитивный корень. Корень \(\zeta_{10}^k\) примитивен тогда и только тогда, когда \(\text{НОД}(k, 10) = 1\), то есть \(k \in \{1, 3, 7, 9\}\).

Таким образом, группа Галуа состоит ровно из четырёх элементов: \(\{\sigma_1, \sigma_3, \sigma_7, \sigma_9\}\), и изоморфна \((\mathbb{Z}/10\mathbb{Z})^\times\).

Поскольку \(10 = 2 \times 5\) и оба множителя простые, справедливо разложение:

\[ \mathbb{Q}(\zeta_{10}) \cong \mathbb{Q}(\zeta_5) \]

(так как \(\zeta_{10} = -\zeta_5^3\)), и группа Галуа изоморфна:

\[ \text{Gal}(\mathbb{Q}(\zeta_5)/\mathbb{Q}) \cong (\mathbb{Z}/5\mathbb{Z})^\times \cong \mathbb{Z}_4 \]

### 3.3. Цикличность группы \(\mathbb{Z}_4\) и алгебраическая генерация каналов

Группа \(\{1, 3, 7, 9\}\) по умножению mod 10 является **циклической** и порождается элементом **3** (или **7**):

| Шаг | Вычисление | Результат (канал) |
|-----|------------|-------------------|
| \(\sigma_3^1\) | \(3^1 \equiv 3\) | канал `…3` |
| \(\sigma_3^2\) | \(3^2 = 9 \equiv 9\) | канал `…9` |
| \(\sigma_3^3\) | \(3^3 = 27 \equiv 7\) | канал `…7` |
| \(\sigma_3^4\) | \(3^4 = 81 \equiv 1\) | канал `…1` (единица) |

Это имеет прямое **алгоритмическое применение**: маску для канала `…3` можно получить из маски канала `…1` сдвигом позиций, маску для `…9` — двойным сдвигом, а маску для `…7` — тройным. Зная поведение одного канала, можно алгебраически восстановить все остальные без дополнительных вычислений по модулю.

## 4. Глобальная периодичность и Китайская теорема об остатках (КТО)

### 4.1. Формирование больших периодов (840, 1680, 2520…)

Делимость числа \(10k + d\) на простое `p` зависит только от \(k \bmod p\). Это означает, что для каждого простого `p` маска периодична с периодом `p`. Когда в решете одновременно работают несколько простых чисел \(p_1, p_2, \ldots, p_n\), глобальная структура становится периодичной с периодом \(\text{НОК}(p_1, p_2, \ldots, p_n)\).

Числа `840, 1680, 2520, 3360, 4200` в колонках `M, Q, S, U, W` листа E — это кратные числа 840:

\[ 840 = 2^3 \times 3 \times 5 \times 7 = \text{lcm}(1,2,\ldots,7) \times 3 \]

Число 840 является наименьшим общим кратным нескольких малых простых и служит базовым «шагом колеса» факторизации. Остатки и дополнения в колонках `M–X` позволяют вычислять позиции следующих попаданий простого `p` на всём диапазоне до `4200`.

### 4.2. Роль КТО в факторизации с колесом (Wheel Factorization)

**Китайская теорема об остатках** утверждает: если \(m_1, m_2, \ldots, m_r\) попарно взаимно просты, то система сравнений

\[ x \equiv a_1 \pmod{m_1}, \quad x \equiv a_2 \pmod{m_2}, \quad \ldots, \quad x \equiv a_r \pmod{m_r} \]

имеет единственное решение по модулю \(M = m_1 \cdot m_2 \cdots m_r\).

В контексте решета КТО означает: если известны остатки числа по модулям 2, 3, 5, 7, можно однозначно определить его позицию в цикле длиной \(2 \times 3 \times 5 \times 7 = 210\) (или `840`). Это позволяет:

- Предвычислить полный паттерн «выживших» кандидатов за один проход по циклу.
- Затем тиражировать этот паттерн на весь диапазон поиска без повторных делений.
- Вычислять позицию следующего попадания простого `p` как решение линейного сравнения через КТО, а не перебором.

## 5. Симметрия масок и инволюции

### 5.1. Зеркальная симметрия hex-символов (7 ↔ e, b ↔ d)

В структуре битовых символов `7, b, d, e` существует явная зеркальная симметрия:

| Символ | Канал | «Зеркало» | Канал-партнёр |
|--------|-------|-----------|---------------|
| `7`  | выбит `…1` | `e` | выбит `…9` |
| `b`  | выбит `…3` | `d` | выбит `…7` |

Эта симметрия не случайна. Она следует из того, что:

\[ 1 + 9 \equiv 0 \pmod{10}, \quad 3 + 7 \equiv 0 \pmod{10} \]

То есть каналы `…1` и `…9` являются «аддитивными обратными» друг другу по модулю 10, как и пара `…3`/`…7`. Аналогично, если число `n = 10k + 1` делится на `p`, то число `10k + 9` при отражении относительно центра даёт пару симметричного попадания.

В колонке `H` листа E это видно непосредственно: для каждого `p` порядок четырёх специальных символов принадлежит одному из нескольких «зеркальных» паттернов.

### 5.2. Автоморфизмы и инволюции в группе вычетов

Зеркальное отображение \(k \mapsto -k \pmod{10}\) (то есть \(1 \leftrightarrow 9, 3 \leftrightarrow 7\)) — это **инволюция**: применённая дважды, она даёт тождественное преобразование. В терминах теории групп это автоморфизм порядка 2 группы \((\mathbb{Z}/10\mathbb{Z})^\times\).

Практическое следствие: маска для прогрессий «с начала» (малые `k`) зеркально определяет маску для прогрессий «с конца» (большие `k`). Это позволяет **хранить в памяти только половину маски**, восстанавливая вторую половину отражением.

Порядок специальных символов в колонке `H` (7bde, be7d, d7eb, edb7) сам образует циклическую структуру — это орбита одного элемента под действием автоморфизмов \(\sigma_3\).

## 6. Геометрические интерпретации: от 2D к 4D

### 6.1. Комплексная плоскость: корни 10-й степени из единицы

Десять корней из единицы \(\zeta_{10}^k = e^{2\pi i k/10}\) для \(k = 0, 1, \ldots, 9\) образуют правильный **10-угольник** на комплексной плоскости.

Эти корни естественно делятся на две группы:

- **Чётные степени** \(\zeta_{10}^0, \zeta_{10}^2, \zeta_{10}^4, \zeta_{10}^6, \zeta_{10}^8\) — образуют правильный **пятиугольник** (корни уравнения \(z^5 = 1\)).
- **Нечётные степени** \(\zeta_{10}^1, \zeta_{10}^3, \zeta_{10}^5, \zeta_{10}^7, \zeta_{10}^9\) — образуют второй повёрнутый **пятиугольник** (корни уравнения \(z^5 = -1\)).

Наши четыре «рабочих» канала \(\{1, 3, 7, 9\}\) — это четыре из пяти вершин второго пятиугольника. Пятая вершина (степень 5) исчезает по причине, разобранной в следующем разделе.

### 6.2. Функция Эйлера и парадокс «пропавшего 5-го луча»

Среди пяти нечётных индексов \(\{1, 3, 5, 7, 9\}\) функция Эйлера оставляет только четыре. Причина: \(\varphi(10)\) считает числа, **взаимно простые с 10**, а число 5 не удовлетворяет этому условию (\(\text{НОД}(5, 10) = 5 \neq 1\)).

Геометрически пятый корень соответствует:

\[ \zeta_{10}^5 = e^{\pi i} = -1 \]

Это не просто «потерянная» вершина пятиугольника, а специальная точка, которая лежит строго на действительной оси. Число \(-1\) порождает подгруппу порядка всего **2** (\(\{-1, 1\}\)), а не 10. Соответственно, индекс 5 соответствует арифметической прогрессии \(10k + 5\), все элементы которой делятся на 5 и **не могут быть простыми** (кроме самой пятёрки).

Итог: «пятый луч» — это не потеря информации. Это алгебраически вырожденная вершина, отвечающая за делимость на 5. Она изначально исключается из кандидатов вместе с чётными каналами (делимость на 2).

### 6.3. Группа \(\mathbb{Z}_4\) как вращение 2D-квадрата

Циклическая группа порядка 4 реализуется в 2D как группа **вращений квадрата** (без отражений):

- Образующий элемент — поворот на \(90^\circ\)
- Матрица поворота: \(\begin{pmatrix} 0 & -1 \\ 1 & 0 \end{pmatrix}\)
- Последовательность: \(0^\circ \to 90^\circ \to 180^\circ \to 270^\circ \to 360^\circ\) (тождественный)

Если назначить четырём вершинам квадрата четыре канала \((…1, …3, …7, …9)\), то поворот на \(90^\circ\) реализует именно умножение на 3 по модулю 10:

\[ 1 \xrightarrow{\times 3} 3 \xrightarrow{\times 3} 9 \xrightarrow{\times 3} 7 \xrightarrow{\times 3} 1 \]

Это не просто аналогия — это строгий изоморфизм: группа вращений квадрата \(C_4\) изоморфна \((\mathbb{Z}/10\mathbb{Z})^\times \cong \mathbb{Z}_4\).

### 6.4. Проекция на 4D: Изоклинные вращения тессеракта на 90°

Тессеракт (4D-гиперкуб) — это 4-мерный аналог куба. В 4-мерном пространстве вращения происходят не вокруг **оси** (как в 3D), а вокруг **плоскости**. Это означает, что одновременно существуют два независимых «угла вращения».

**Изоклинное (двойное) вращение** — это особый тип 4D-вращения, при котором объект вращается одновременно в двух взаимно ортогональных плоскостях с одинаковым углом:

- Плоскость \(XY\): поворот на \(90^\circ\)
- Плоскость \(ZW\): поворот на \(90^\circ\)

При таком изоклинном вращении каждая точка тессеракта движется по окружности, ни одна точка пространства (кроме начала координат) не остаётся неподвижной. После **4 таких шагов** (т.е. на \(360^\circ\)) каждая точка возвращается в исходное положение.

Подгруппа симметрий тессеракта, порождённая этим вращением, изоморфна \(\mathbb{Z}_4\).

### 6.5. Циклическая перестановка осей (X→Y→Z→W→X) как эквивалент сдвига масок

Назначим четырём координатным осям тессеракта четыре канала нашего решета:

\[ X \leftrightarrow \text{канал }…1, \quad Y \leftrightarrow \text{канал }…3, \quad Z \leftrightarrow \text{канал }…9, \quad W \leftrightarrow \text{канал }…7 \]

Тогда изоклинное вращение тессеракта на \(90^\circ\) — то есть циклическая перестановка осей \(X \to Y \to Z \to W \to X\) — в точности соответствует алгебраической операции «умножить на 3 по модулю 10»:

\[ …1 \xrightarrow{\times 3} …3 \xrightarrow{\times 3} …9 \xrightarrow{\times 3} …7 \xrightarrow{\times 3} …1 \]

Это означает, что **одна итерация изоклинного вращения тессеракта на 90° алгебраически эквивалентна переходу от маски одного канала к маске следующего**. Геометрически — орбита точки под действием этого вращения обходит все четыре канала и замыкается после четырёх шагов.

## 7. Практические выводы для алгоритмической оптимизации

### 7.1. Сокращение объёма памяти в 2 раза за счёт зеркальности

Инволюция \(k \mapsto -k \pmod{p}\) означает, что маска для второй половины периода \(\{k : k > p/2\}\) является зеркальным отражением первой половины \(\{k : k \leq p/2\}\). Это позволяет хранить только «левую» половину строки в памяти и восстанавливать правую по формуле отражения, вдвое снижая расход памяти при хранении набора масок.

Та же симметрия означает, что пары символов `7`/`e` и `b`/`d` в маске появляются симметрично относительно середины строки. Алгоритм может проверять пары позиций одновременно (в одном шаге), ещё вдвое ускоряя проход по маске.

### 7.2. Вычисление масок сдвигом вместо деления по модулю

Поскольку четыре канала связаны циклической группой \(\mathbb{Z}_4\), порождённой умножением на 3, достаточно:

1. Вычислить одну «базовую» маску — например, для канала `…1` (позиции `k`, где `p | 10k+1`).
2. Остальные три маски получить **сдвигом**: позиция \(k_3\) для канала `…3` вычисляется как \(k_3 = (k_1 - \text{inv}(10) \cdot 2) \bmod p\), и аналогично для `…7` и `…9`.

Это заменяет три отдельных решения линейных сравнений одним решением и тремя простыми модульными сдвигами.

Псевдокод оптимизированного построения масок:

```python
def cleaned_mask_fast(p):
    inv10 = pow(10, -1, p)          # обратный элемент к 10 по модулю p
    k1 = (-1 * inv10) % p           # позиция для канала …1
    k3 = (-3 * inv10) % p           # позиция для канала …3
    k7 = (-7 * inv10) % p           # позиция для канала …7
    k9 = (-9 * inv10) % p           # позиция для канала …9

    mask = ['f'] * p
    mask[k1] = '7'
    mask[k3] = 'b'
    mask[k7] = 'd'
    mask[k9] = 'e'

    q = p // 10                     # позиция самовычёркивания
    mask[q] = 'f'                   # очистка самопопадания

    return "".join(mask)
```

Заметим, что четыре позиции \(k_1, k_3, k_7, k_9\) связаны уже разобранным мультипликативным сдвигом, что позволяет вычислять их последовательно без четырёх независимых вызовов `pow`.

### 7.3. Возможности для независимого распараллеливания

Четыре канала `…1`, `…3`, `…7`, `…9` полностью независимы друг от друга в рамках одного шага решета. Каждый канал можно просеивать в отдельном потоке или на отдельном ядре процессора:

- **Поток 1**: отмечает составные вида `10k+1`
- **Поток 2**: отмечает составные вида `10k+3`
- **Поток 3**: отмечает составные вида `10k+7`
- **Поток 4**: отмечает составные вида `10k+9`

После завершения все четыре битовых потока объединяются побитовым `AND` в итоговую маску. Такая схема даёт теоретическое ускорение до 4× при наличии 4 параллельных вычислительных единиц.

Дополнительно, структура больших периодов (840, 1680, ...) на основе КТО позволяет разбить весь диапазон поиска на блоки длиной 840 и обрабатывать их независимо — это второй уровень параллелизма, ортогональный первому.
